# Introducción al lenguaje TypeScript y al framework NestJS

> ⚠️ **Este repositorio no es un proyecto de software.** No hay ninguna aplicación que instalar, ningún paquete que publicar ni problemas de código que corregir: se trata de **material de curso**, escrito para estudiantes que aprenden TypeScript y luego el framework NestJS.

## 📖 Lea el curso

El curso puede leerse en línea en esta dirección:

**👉 [https://stahe.github.io/ales-typescript-nestjs-sept-2026/](https://stahe.github.io/ales-typescript-nextjs-sept-2026/)**

No se requiere ninguna instalación para leerlo: basta con un simple navegador.

## 🎯 ¿A quién está dirigido este curso?

Este curso está dirigido a estudiantes que **no tienen conocimientos previos** de
TypeScript ni de NestJS. Comienza con los fundamentos del lenguaje TypeScript y avanza gradualmente hacia la construcción de aplicaciones completas con el
, mediante numerosos ejemplos de código completamente comentados, línea por línea.

## 📚 Esquema del curso

El curso está organizado en grandes secciones:

1. **Los fundamentos de TypeScript** — configuración del entorno de desarrollo,
   sintaxis del lenguaje, tipado estático, programación orientada a objetos.
2. **Funciones HTTP en TypeScript** — construcción de un servidor HTTP y un cliente HTTP
   en TypeScript puro, antes de introducir cualquier framework.
3. **Acceso a bases de datos** — una comparación de tres enfoques: el
   `mysql2` nativo, el ORM [TypeORM](https://typeorm.io/) y el ORM [Prisma](https://www.prisma.io/).
4. **El framework NestJS** — introducción al framework, su arquitectura MVC,
   gestión de solicitudes (acciones/respuestas), la capa de modelo y el acceso a datos
   con NestJS.
5. **Un caso de estudio completo** — migración de un servidor de cálculo del impuesto sobre la renta, escrito originalmente en PHP, a NestJS: controladores, capas DAO y
   de lógica de negocio, gestión de sesiones y construcción de páginas HTML con plantillas EJS.
